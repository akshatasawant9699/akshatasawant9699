## 🔨 Now building

**[sf-ops-agent](https://github.com/akshatasawant9699/sf-ops-agent)**: an eval-tested Salesforce ops agent, built in public.
It's an MCP server that lets an LLM agent look up accounts, summarise open cases and create follow-up tasks in a Salesforce Developer Edition org. It comes with a golden dataset, an LLM-as-judge eval harness, tracing and evals in CI.

`Python` · `MCP` · `LLM evals` · `pytest` · `Salesforce REST API`
